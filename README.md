# Chief Mate Prep

Offline-first PWA that prepares Second Officers for the **Chief Mate CoC (STCW II/2)** in the Philippines, Nigeria, UK, Ghana and Singapore (Australia and Egypt coming soon), with an **oral examiner** that works with no signal.

- **289 original items** (182 MCQ, 69 orals with examiner key points, 18 randomised calculation types, 9 written, 11 lessons) + **20 COLREGs scenarios**. All **draft, pending expert review**.
- Learning techniques: spaced repetition, confidence calibration, interleaving, worked examples with fading, timed mocks, voice orals, and a readiness gate set **above** real pass marks.
- Deterministic calculation engine (100% tested). AI never computes answers.

```bash
pnpm install && pnpm dev     # http://localhost:5173
pnpm ci:all                  # full verification
```
